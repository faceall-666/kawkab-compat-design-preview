# معاينة تصميم التوافق

صفحة البداية الأصلية المختارة: شاشة البيانات، الحلقة والمحاور الخمسة، وصندوق فتح القصة الكاملة. بعد الفتح تنتقل إلى القراءة المصورة والباقات التجريبية. التصميم ومواقع العناصر والأزرار من النسخة الأصلية المحفوظة.

هذه معاينة تصميم فقط؛ جميع النسب أمثلة ثابتة. لا حساب فلكي أو دفع حقيقي أو اتصال API أو إرسال لبيانات الميلاد. الحفظ التجريبي في ذاكرة الصفحة فقط ويزول عند إعادة تحميلها.
