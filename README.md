# معاينة تصميم التوافق

هذه نسخة عرض مستقلة للتصميم المصور: شاشة البيانات، نتائج المثال، الفصول، الصور، الباقات والفتح التجريبي. الأسماء والتواريخ لا تستخدم لحساب النتائج؛ الأرقام والنصوص أمثلة ثابتة، ولا يوجد دفع حقيقي أو إرسال أو حفظ لبيانات الإدخال.

محرك الحساب الخاص غير موجود في هذه المعاينة. يمكن التبديل بين عرض غير المشترك والمشترك لتجربة العناصر، كما يمكن إظهار الفصول العاطفية من مفتاحها. الأسعار المعروضة مقترحات تصميم قديمة وليست تسعيرا معتمدا.
